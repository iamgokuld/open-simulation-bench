Open Simulation Bench

A virtual lab for testing how measurement noise, losses and conditions change the outcome of an experiment. Pick an experiment, run it, and compare what the model predicts with what the simulated instruments read. Every run is seeded, so any result can be repeated.

      All logged runs

      What this plot shows

      Each row is one quantity. The horizontal axis is the % error of a run, which is how far the measured value landed from the predicted value, with the direction kept. Left of the zero line the reading came out lower than predicted (▼), right of it higher (▲). The closer to the zero line, the better the prediction held.

      • Grey line. Zero error: measured equals predicted.
      • Dark dot. One earlier logged run.
      • Gold dot. The run shown on this page, the latest one.
      • Dark bar. The mean error of every logged run.
      • +3.1 % ± 2.4. Mean error, then the standard deviation (SD): the typical spread of single runs around the mean. It reads 0.0 until there are two runs.
      • Axis ends. Runs beyond ±30 % are drawn on the edge.

      How to read it. A bar well away from the zero line is bias, a steady offset that repeats every run. A wide scatter of dark dots is noise, random run-to-run variation. Use 20 or more runs before trusting either.

      How to conduct an experimentabout ten minutes
      1. 01Ask one questionWrite it down first, for example "does humidity change the error?". Why: a clear question tells you which condition to change and which quantity to watch.
      2. 02Set a baselineLeave the conditions at their starting values, press Run ×20 and note the mean and spread for the quantity you care about. Why: the spread of the baseline is the noise floor that any effect has to beat.
      3. 03Change one thingMove a single slider, then press Run ×20 again with Clear log in between. Why: if two conditions change together you cannot tell which one caused the difference.
      4. 04Repeat, do not trust one runUse at least 20 runs for each setting. Why: one run is one random sample and can sit far from the typical result.
      5. 05Compare means against the spreadA change in the mean that is clearly larger than the baseline spread, about twice it as a rule of thumb, is probably real. Why: a smaller change can come from noise alone.
      6. 06Find the causeOpen What actually happened and What moves the error. Why: they show which disturbance or condition produced the error, so the next change is a guess with a reason.
      7. 07Fix it and test againChange the condition you blame, such as a longer wait, and run again with the same seed. Why: with the noise held fixed, any difference comes from your change.
      8. 08Report it so others can repeat itState the experiment, the conditions, the number of runs, the mean ± SD and one seed. Why: anyone can type that seed and see the same run. Say that the numbers are simulated.

      Common mistakes. Changing two conditions at once. Judging from a single run. Reading only the size of an error and missing its direction, which tells bias from noise.
